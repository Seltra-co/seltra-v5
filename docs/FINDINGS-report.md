### Execution, install, scaffold, and preview

- `[CONFIRMED]` The gateway launches a Node runtime child process with `spawn`; RPC binds to loopback and uses a per-runtime secret. This implementation does not launch a container or VM (`seltra-web/core/server/src/workspace_supervisor.ts:119-168`). The runtime README states that container/network/resource controls must be supplied by an orchestrator and that the runtime is not isolated until those controls are applied and tested (`seltra-web/core/runtime/README.md:25-41`).
- `[PARTIAL]` Package-manager socket-firewall tooling exists, but is not workspace-level CPU, memory, filesystem, or network isolation (`seltra-web/core/src/ipc/utils/socket_firewall.ts:54,678-709,1137-1246`).
- `[CONFIRMED]` Agent `run_shell` is feature/Pro-gated; it calls `reviewShellCommand()` for allow/ask/block, requires consent, then executes in the app directory. Shell-review fallback is block; policy forbids background jobs and says commands must finish within five minutes (`seltra-web/core/src/pro/main/ipc/handlers/local_agent/tools/run_shell.ts:34-38,79-97,131-157,172-203`; `seltra-web/core/src/pro/main/ipc/handlers/local_agent/shell_review.ts:211-213`; `seltra-web/core/src/prompts/shell_review_policy.ts:10-18`).
- `[CONFIRMED]` `timeout_ms` is capped at 300,000 ms and defaults to 60,000 ms; output is bounded to 64,000 characters, and timeout/cancel kills the process tree. Build checks have a 10-minute timeout and a three-build-per-turn cap (`seltra-web/core/src/pro/main/ipc/handlers/local_agent/tools/shell_process.ts:133-210`; `seltra-web/core/src/pro/main/ipc/handlers/local_agent/tools/run_shell.ts:203-210`; `seltra-web/core/src/pro/main/ipc/handlers/local_agent/tools/run_build.ts:42-43,380-388,461-462`).
- `[CONFIRMED]` The installer supports npm and pnpm, detects workspace roots, and selects install commands; install is executed via `spawnStreaming`. No Core-managed shared dependency cache was found in the installer (`seltra-web/core/src/ipc/services/isolated_package_install.ts:131-152,237-297,308-355`).
- `[CONFIRMED]` App creation runs through `appContracts.createApp` → `createFromTemplate()` → Git initialization. Default template ID is `react`; available template list includes Next, Vite+Nitro, and Portal mini-store; template sources are in `seltra-web/core/scaffold/` (`seltra-web/core/src/ipc/handlers/app_handlers.ts:856-952`; `seltra-web/core/src/shared/templates.ts:21-22,34-64`).
- `[CONFIRMED]` The gateway serves previews by resolving an app preview port; host-based preview URL behavior is part of the gateway path, while missing/not-running preview resolution returns `PREVIEW_NOT_FOUND` (`seltra-web/core/server/src/main.ts:1025-1044,1885-1901`). The existence of preview service is not evidence that a workspace can be restored from GitHub.
